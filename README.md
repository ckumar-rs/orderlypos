# OrderlyPOS website

Public site for OrderlyPOS. Host it on Vercel.

Set these before the Vercel build:

- `NEXT_PUBLIC_SITE_URL` — `https://orderlypos-eight.vercel.app`
- `NEXT_PUBLIC_APP_URL` — the admin and kiosk app on Vercel. Try now and Sign in open that origin. Until this is set, those links stay on this site and `/login` does not exist here.

The till, the kiosk, and the API are not in this repository.
