# OrderlyPOS website

Public site for OrderlyPOS. Host it on Vercel.

Set these before the Vercel build:

- `NEXT_PUBLIC_SITE_URL` — this site’s public origin, used for the sitemap and link preview
- `NEXT_PUBLIC_APP_URL` — the admin and kiosk app. Try now and Sign in open that origin

The till, the kiosk, and the API are not in this repository.
